# MARBLE RACE – Đường đua học sinh may mắn

Trò chơi chọn ngẫu nhiên một học sinh bằng đường đua viên bi 3D có ảnh đại diện mặc định, nhiều kiểu bi, hiệu ứng vật lý, âm thanh, ánh sáng, camera và popup vinh danh.

## Sử dụng ngay

- Trên hệ thống giáo viên: https://giaovien-psi.vercel.app/marble-race/
- Mã nguồn độc lập: `index.html` trong repository này.

## Kích hoạt GitHub Pages cho repository Bi

1. Mở **Settings → Pages** trong repository `huunsbk/Bi`.
2. Ở **Build and deployment**, chọn **Deploy from a branch**.
3. Chọn nhánh **main** và thư mục **/(root)**, sau đó nhấn **Save**.
4. Sau khi GitHub hoàn tất triển khai, trang độc lập sẽ có địa chỉ `https://huunsbk.github.io/Bi/`.

GitHub Pages cần được bật một lần bởi chủ tài khoản qua phần Settings; việc tải mã nguồn lên GitHub chưa tự động bật hosting.

## Cách dùng

Dán danh sách học sinh (mỗi dòng một tên), nhấn **Tạo danh sách**, điều chỉnh thời gian, rồi nhấn **Bắt đầu cuộc đua**. Khi có kết quả, popup vinh danh xuất hiện. Có thể chọn tiếp và loại trừ học sinh đã được chọn.

Thông tin danh sách và ảnh được lưu cục bộ trên trình duyệt đang sử dụng. Ứng dụng không cần cơ sở dữ liệu hoặc tài khoản.
